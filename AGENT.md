# AGENT Pricing & Service Reference

This file is a quick reference for preparing offer pages in this repository.

## Current Offer Context
- Project type: On-demand car services platform.
- Total price: EGP 150,000.
- Duration: 4 months.
- Delivery scope:
  - Customer app: Android + iOS
  - Service provider app: Android + iOS
  - Admin website
  - Background team: website
  - Customer service: website

## Payment Milestones
- 25% advance at contract signing.
- 25% after Admin app delivery (mobile + desktop).
- 25% after Service Provider app delivery.
- 25% after Customer app completion.

## Free Services (Default in this offer)
- Free server during implementation period.
- Free technical support for 6 months after delivery.
- Pre-launch readiness support (QA, performance review, go-live checks).

## Post-Free Subscriptions
### Technical Support Subscription
- EGP 10,000 yearly.
- Includes:
  - Continuous server maintenance.
  - Security updates for server and full system.
  - Fixing runtime/production errors.
  - Priority support responses.
  - Proactive update notifications.
  - Ongoing enhancement recommendations.

### Server Packages
- Dedicated server: EGP 6,000 yearly (server cost only).
- Shared server: EGP 3,000 yearly.
- Notify client when higher capacity/tier is needed.
- Upgrade/migration to higher tier is free of charge.

## App Store Account Options
### Option A: Company Accounts
- Apple: USD 60/year.
- Google: USD 20/year.
- Includes periodic maintenance and compliance alerts.
- Free transfer to client-owned accounts upon request.

### Option B: Client-Owned Accounts
- Apps published directly on client accounts.
- Annual store-support subscription: USD 50/year for both platforms.
- If apps remain on company accounts, ongoing platform follow-up is company responsibility.

## Usage Guidance for Future Edits
When user says "add free services" in this offer context, include by default:
1) Free server during implementation.
2) Free technical support for 6 months after delivery.
3) Pre-launch readiness support.

When user asks for "post-delivery costs", include by default:
1) Support subscription EGP 10,000/year.
2) Server package based on deployment:
   - Dedicated EGP 6,000/year
   - Shared EGP 3,000/year
   - Free migration to higher tier when needed
3) Store account options (company vs client accounts) with the pricing above.

Always confirm if the user wants to keep these defaults or override them for a new branch/project.
