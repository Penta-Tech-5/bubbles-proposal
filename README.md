# عرض سعر - منصة رقمية لعرض المنتجات

## معلومات عامة
- اسم المشروع: منصة رقمية لعرض المنتجات.
- السوق المستهدف: العراق.
- الإصدار: 1.0.
- المنصات المطلوبة: تطبيق Android، تطبيق iOS، ولوحة تحكم ويب.
- التكلفة الإجمالية: 1200 دولار.
- مدة التنفيذ: 60 يوم بعد تنفيذ التصميمات وموافقة العميل عليها.

## فكرة المشروع
المنصة ليست متجرًا إلكترونيًا ولا تقوم ببيع المنتجات أو استقبال الأموال. وظيفة المنصة هي عرض المنتجات، ربط المشترين بالبائعين، وتسهيل التواصل المباشر عبر WhatsApp.

جميع عمليات البيع، الدفع، الاتفاق، الشحن، والتوصيل تتم خارج المنصة بين المشتري والبائع.

## أهداف المشروع
- تمكين البائع من إنشاء متجر إلكتروني احترافي بتكلفة أقل.
- مساعدة البائع على عرض المنتجات والوصول إلى عملاء أكثر.
- تسهيل بحث المشتري عن المنتجات داخل واجهة عربية منظمة.
- ربط المشتري بالبائع مباشرة عبر WhatsApp.
- بناء نظام قابل للتوسع والتطوير مستقبلًا.

## التسجيل والحسابات
- تسجيل المشتري: الاسم، رقم الهاتف، البريد الإلكتروني اختياري، كلمة المرور، المدينة، اللغة.
- تسجيل البائع: البيانات الشخصية، بيانات النشاط التجاري، بيانات المتجر، وسائل التواصل.
- حالات حساب البائع: Pending، Approved، Rejected، Suspended.
- يدعم النظام تسجيل الدخول واستعادة كلمة المرور.

## إدارة المتاجر
- كل بائع يستطيع إنشاء متجر.
- بيانات المتجر تشمل الاسم، الشعار، صورة الغلاف، الوصف، التصنيف، المدينة، ومعلومات التواصل.
- حالات المتجر: Active، Pending، Suspended، Hidden.
- المتاجر الظاهرة للمستخدمين هي المتاجر المعتمدة والنشطة فقط.
- إحصائيات المتجر تشمل عدد الزيارات، مشاهدات المنتجات، ضغطات WhatsApp، وتوزيع حالات المنتجات.

## إدارة المنتجات
- كل منتج يتبع متجرًا واحدًا وبائعًا واحدًا.
- بيانات المنتج تشمل الاسم، الوصف، التصنيف، التصنيف الفرعي، السعر، العملة، الصور، الحالة، المدينة، والمتجر.
- الصور تشمل صورة رئيسية وصور إضافية، وعدد الصور يعتمد على الاشتراك.
- حالات المنتج: Available، Reserved، Sold، Hidden.
- الإدارة تستطيع الموافقة، الرفض، الإخفاء، الحذف، أو طلب التعديل.

## البحث واكتشاف المنتجات
- البحث بالاسم.
- البحث بالتصنيف.
- البحث باسم المتجر.
- البحث باسم البائع.
- البحث بالمدينة.
- البحث بالسعر.
- الترتيب حسب الأحدث، الأقدم، الأقل سعرًا، الأعلى سعرًا، الأكثر مشاهدة، والأعلى تقييمًا.

## تكامل WhatsApp
- كل صفحة منتج تحتوي زر تواصل مع البائع.
- عند الضغط يتم فتح WhatsApp مباشرة.
- الرسالة التلقائية تتضمن رابط المنتج، صورة المنتج، ونص عربي قابل للتعديل من لوحة التحكم.
- المنصة لا تحفظ الرسائل ولا تراقب المحادثات.
- المنصة لا تستقبل الأموال ولا تدير الشحن.
- يستطيع البائع تغيير حالة المنتج إلى Reserved أو Sold بعد التواصل.

## الاشتراكات
- المشتري يستخدم المنصة مجانًا.
- الاشتراكات للبائعين فقط.
- الفترة التجريبية افتراضيًا 30 يومًا ويمكن تعديلها من لوحة التحكم.
- الباقات المقترحة: Trial، Bronze، Silver، Gold.
- يمكن التحكم في عدد المنتجات، عدد الصور، عدد المتاجر، التقارير، الإحصائيات، وأدوات الإدارة حسب الباقة.
- لا يوجد دفع داخل التطبيق في الإصدار الأول.
- عند الضغط على Subscribe يتم إنشاء طلب اشتراك ويتواصل البائع مع الدعم.
- الإدارة تفعل الاشتراك يدويًا بعد التأكد من الدفع.
- حالات طلب الاشتراك: New، Contacted، Waiting for Payment، Payment Confirmed، Subscription Activated، Cancelled.

## التقييمات والبلاغات
- يمكن تقييم البائع والمنتج بعدد نجوم وتعليق.
- الإدارة تستطيع إخفاء التقييم أو حذفه أو استعادته.
- يمكن الإبلاغ عن منتج، متجر، حساب بائع، صورة، وصف، أو تقييم.
- أسباب البلاغ تشمل معلومات خاطئة، منتج مزيف، صور مضللة، سبام، احتيال، حقوق نشر، أو محتوى مسيء.
- حالات البلاغ: New، Under Review، Resolved، Rejected، Closed.
