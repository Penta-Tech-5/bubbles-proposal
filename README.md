# عرض سعر - منصة طبية لإدارة المرضى والروشتات

## معلومات أساسية
- الجهة المقدمة: Penta-k.
- السعر الإجمالي: 60,000 جنيه مصري.
- نوع الحل: Mobile App (iOS + Android) + Web Dashboard للدكتور + صفحة ويب بسيطة للتشغيل اليدوي.
- اللغة: عربي + English.

## نظرة عامة
منصة طبية متكاملة لإدارة بيانات المرضى، الروشتات الإلكترونية، الإشعارات الطبية، المدفوعات، وتتبع التوصيل، مع لوحة ويب للطبيب وصفحة ويب Frontend بسيطة بدل Google Forms وWhatsApp.

## النطاق المشمول
- تطبيق موبايل للمرضى على iOS و Android.
- Web Dashboard للدكتور.
- صفحة ويب بسيطة للتشغيل اليدوي بالكامل.
- تخزين بيانات طبية آمن.
- نظام روشتة إلكترونية.
- Notifications لمواعيد الجرعات.
- Payment عبر Instapay و Fawry والكروت البنكية.
- Delivery tracking.
- Analytics وتقارير تشغيلية.
- Role-based access.

## مميزات تطبيق المريض
- تسجيل ومتابعة البيانات الطبية بشكل آمن.
- استلام الروشتات إلكترونيًا.
- تنبيهات مواعيد الجرعات.
- متابعة حالة الطلب والتوصيل.
- الدفع داخل النظام بوسائل متعددة.

## مميزات لوحة الدكتور
- إدارة ملفات المرضى.
- إصدار ومراجعة الروشتات.
- متابعة الحالات والزيارات.
- صلاحيات حسب الدور الوظيفي.
- رؤية تشغيلية وتحليلات أساسية.

## الويب البسيط للتشغيل اليدوي
- صفحة Frontend فقط.
- بديل مباشر لـ Google Forms وWhatsApp.
- تشغيل يدوي بالكامل.
- تسجيل الطلبات وتوزيعها بصورة أبسط.

## السعر وطريقة السداد

- طريقة السداد: يتم الاتفاق عليها مع العميل بعد اعتماد التفاصيل النهائية.
